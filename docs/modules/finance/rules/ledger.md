El clasificador emite `accountNumberLast4`, `movementClass CARD_PAYMENT`, `suggestedTransactionDate` con procedencia `EMAIL_HEADER` y `reverseOfEmailMessageId`; la verificación humana acepta las mismas pistas. Finance solo consume `accountNumberLast4` en la transferencia (PR #340).

## Bank status → interno

`shared/domain/transaction-status.ts`. Confidence &lt; 0.7 o `UNKNOWN` → `PENDING`. `APPROVED`/`COMPLETED`/`POSTED` → `CONFIRMED`. `PENDING`/`IN_PROGRESS`/`AUTHORIZED` → `PENDING`. `DECLINED`/`REJECTED`/`FAILED` → `DECLINED`. `CANCELLED`/`VOIDED` → `CANCELLED`. `REVERSED`/`REFUNDED`/`CHARGEBACK` → reverse original si existe + `REVERSED`.
