# Programa de Intelligence y Email

## Diagnóstico

El corte AI-0 retiró el runtime anterior de chat y la propiedad de Gmail que estaba mezclada con Finance. Las fases posteriores reconstruyen Intelligence alrededor de una fuente de correo aislada por usuario, evidencia verificable, conocimiento con alcance explícito y señales que no mutan por sí mismas los dominios.

## Objetivo

Entregar el ciclo de inteligencia de correo con privacidad por usuario, evidencia trazable y pruebas/gates por fase. Finance consume señales mediante contratos propios; la IA accede a dominios por capacidades registradas. El programa se sigue en [#193](https://github.com/jarvinc3/personal-os-back/issues/193).
